{title:Server restart for security and other fixes}
{date:2026-09-24}

The game server was restarted to bring the server software up to date.
Most of the work was under the hood: security fixes, smaller corrections,
and some new features for the upcoming TMW update.

A few changes should be noticeable in game:

{ul}
{li}Monsters and players no longer skip a quarter step forward when their
  destination changes, so there should be fewer position corrections{/li}
{li}The overweight status and its icon are restored correctly after
  respawning{/li}
{li}New quest variables no longer inherit leftover state, which could
  mess up some quests, like the Blue Sage quest{/li}
{/ul}
